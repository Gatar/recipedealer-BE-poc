Zrzuty według stanu

Puste pole limitu lub budżetu = bez limitu. Niższy limit niczego nie usuwa, tylko blokuje nowe przepisy. Budżet liczy się w miesiącu kalendarzowym (UTC).

Nowy dom

Dom bez użytkowników, poza limitem domów. Daj komuś kod zaproszenia: pierwsza osoba, która dołączy, zostaje właścicielem.

Dodaj urządzenie (rejestracja przez admina)

Nowy użytkownik trafia do wybranego domu, bez hasła (ustawi je w aplikacji). Istniejący zachowuje swój dom.

Pełna kopia: zrzut bazy + wszystkie pliki. Odtwarzanie tylko na serwerze (deploy/restore.sh).
